# Data sources and licenses

Only datasets with confirmed licenses are used (SRS C-9). Per AGENTS rule 7, real messages enter the repo only as already-public datasets whose license allows redistribution: PH Spam + Marketing SMS, Tagalog-SMS and Mishra & Soni are committed unmodified in `data/raw/` (credits in `data/raw/README.md`). UCI is not committed; download it with `training/fetch_uci.py`.

## Our own data (license: original, same as the repo)

The Qwen fine-tuning pipeline in `training/qwen/` reads explicit canonical paths and keeps derived data local in gitignored `training/qwen/artifacts/`. Its label policy distinguishes unsolicited `spam` (Suspicious) from explicit `smishing`/`scam` (Scam) and `ham`/legitimate source categories (Low risk, not a safety guarantee). It excludes missing/redacted/blank content, quarantines contradictory normalized labels, and splits message families before selecting a balanced training subset. The generated manifest records source hashes, exclusions, split hashes and limitations. Source files stay unchanged, and `data/test_v2` remains frozen and outside training/tuning. This trains classification only; the datasets do not provide human-authored Taglish explanation targets. AI-written synthetic rows still need team review.

Every message is fictional: invented codes, amounts and reference numbers, "Juan Dela Cruz"-style names, `09XX-XXX-XXXX` numbers, and fake links only on reserved domains (`.example`). Exception: the older `team_written.csv` rows use made-up domains with real-world endings such as `.xyz` and real shortener hosts; they are training data only.

Source labels in the `source` column:

- `synthetic-ai`: written by Claude Code (AI). 379 rows plus the 20 LLM cases. The 86 email rows in `data/train_email` and `data/email_test` were written by Devin (AI); their `notes` column says so.
- `advisory-pattern`: original text written by Claude Code following a pattern from a cited public warning (54 rows: 18 patterns x 3 splits). Pattern sources: `data/patterns/ph_scam_patterns.md`.
- `synthetic-team`: written by a teammate. 0 rows so far.

So 100% of our own data is AI-written. The team still needs to review it; add new team-written messages with `source: synthetic-team`.

`data/test/` (the original frozen test set planned in PLAN.md) does not exist yet. `data/test_v2` is never used for training or tuning.

## Pattern sources

Each pattern's public source links (news reports and bank, e-wallet, PNP-ACG, CICC, DSWD, LTO, PHLPost, SEC and BSP advisories) are listed in `data/patterns/ph_scam_patterns.md`. Messages were modeled on the pattern, never copied.

## Images

`data/images/screenshots/` (40 renders) and `data/images/qr/` (12 QR codes) are generated by `scripts/render_screenshots.py` and `scripts/make_qr_codes.py` from the messages above. Fonts: the system font found on the machine that ran the script (Segoe UI on Windows).
