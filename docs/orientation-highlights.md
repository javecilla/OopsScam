## **1\. Executive Summary & Core Challenge**

* **Ang Tema:** **Local AI**. Nangangahulugan ito na ang makabuluhang AI computation ay dapat tumakbo sa mismong device ng user sa halip na umasa lang sa cloud inference. Hindi ito simpleng "paggawa ng app para sa local community".  
* **Ang Challenge Statement:** *"Build an AI product that remains genuinely useful when the cloud disappears."*

* **The "Why Local?" Rule:** Bawat submission ay obligadong ipaliwanag at patunayan kung bakit mas mainam ang on-device inference (e.g., privacy, zero API costs, zero internet latency, offline access) kaysa sa cloud-only setup.  
* **Pwedeng Gamitin:** Open-weight models (Hugging Face), local runtimes tulad ng Ollama, LM Studio, llama.cpp, ONNX, WebGPU, PyTorch, MLX, DirectML, at Core ML. Pwede rin ang AI-assisted coding tools tulad ng Devin/cursor/claude code/codex  
* **Hybrid Systems:** Pinapayagan ang cloud APIs bilang pangalawang component o fallback, ngunit ang core AI intelligence ay hindi dapat nakadepende nang buo sa cloud.

## **4\. Submission Checklist (Bago mag-10:00 AM, Oct 10\)**

Lahat ng entries ay isusumite sa [Cerebral Valley](https://cerebralvalley.ai/e/appbuildersph-hackathon-2026):

> 1. **Project Details:** Pangalan ng app, maikling paglalarawan, at mga miyembro ng grupo kalakip ang kani-kanilang gampanin.  
> 2. **Public GitHub Repository:** Dapat pampubliko pagpatak ng 10:00 AM na may malinaw na setup instructions para masubukan ng hurado. Hindi kailangang naka-deploy sa cloud.  
> 3. **Demo Video (\~1 minuto):** I-post nang pampubliko sa X (dating Twitter) o LinkedIn, i-tag ang **Devin / Cognition**, at gamitin ang hashtag \#AppBuildersPH.  
> 4. **Local vs Cloud Breakdown:** Detalyadong listahan kung aling mga proseso ang lokal na gumagana at alin ang nangangailangan ng internet.  
> 5. **Technical Disclosures:** Pagtukoy sa mga modelong ginamit, frameworks, secondary cloud APIs, at development tools (tulad ng Devin o iba pang coding assistants).  
> 6. **Core Justification:** Sagot sa tanong na: *"Why does this product benefit from running AI locally?"*

## **7\. Compiled Official FAQs**

**Paggamit ng Tools at Teknolohiya**

* **Pwede ba ang cloud APIs?** Oo, basta pangalawang suporta lamang. Hindi pwedeng umasa ang pangunahing AI capability sa cloud API.  
* **Kailangan ba ng partikular na operating system o hardware?** Hindi. Kahit anong OS, hardware (laptop, phone, edge chips), o framework ay tinatanggap.  
* **Pwede bang gumamit ng AI agents gaya ng Devin?** Oo, pinapayagan basta't idedeklara ito sa submission disclosures.

**Pagsusumite at GitHub**

* **Kailangan bang naka-live deploy ang website o app?** Hindi. Sapat na ang kumpletong setup at deployment guide sa README ng public repo upang magaya ito ng judges.  
* **Maaari pa bang mag-commit pagkatapos ng 10:00 AM bukas?** Hindi. May code freeze at ang lagay ng repository sa mismong deadline ang susuriin ng mga hurado.  
* **Maaari bang i-edit ang submission form kapag naipasa na?** Hindi, isang beses lamang pwedeng magsumite ang bawat koponan.

**Kaganapan sa Demo Day**

* **Kailangan bang pumunta sa SM Makati kung hindi sigurado kung finalist?** Bukas ang entablado sa lahat. May inihandang kape, sandwiches, raffle draws, at pagkakataong manalo sa People's Choice Award.
